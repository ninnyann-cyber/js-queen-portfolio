# JS Queen Portfolio

A bold, responsive personal portfolio website for **Ninny Ann**, a front-end developer, JavaScript enthusiast, tech assistant, and creative entrepreneur.

The site showcases Ninny's skills, selected work, areas of research, technical support experience, and creative business interests through a playful, editorial-inspired interface.

## Features

- Responsive portfolio layout for desktop and mobile screens
- Mobile navigation menu with accessible menu state handling
- Smooth scroll navigation between portfolio sections
- Scroll-triggered reveal animations using `IntersectionObserver`
- Active navigation link highlighting based on the visible section
- Cursor-following glow effect on pointer-based devices
- Dedicated sections for:
  - About
  - Skills and services
  - Selected work
  - Research interests
  - Experience
  - Creative work
  - Contact information
- Contact links for email and WhatsApp
- Google Fonts integration using DM Sans and Space Grotesk

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts

## Getting Started

This project is a static website and does not require a build tool, package manager, or framework.

### Run locally

1. Clone the repository:

   ```bash
   git clone https://github.com/ninnyann-cyber/js-queen-portfolio.git
   ```

2. Open the project directory:

   ```bash
   cd js-queen-portfolio
   ```

3. Open `index.html` in a browser.

For the best local development experience, serve the folder with a local web server. For example, if you have Python installed:

```bash
python3 -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## Customization

- Update the text and portfolio content in `index.html`.
- Adjust colors, typography, spacing, responsive breakpoints, and animations in `css/style.css`.
- Modify interactive behavior in `js/script.js`.
- Replace the contact links in the contact section with your own email address, messaging link, and social profiles.
- Add project cards or external project links in the selected work section as the portfolio grows.
